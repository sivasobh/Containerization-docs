# Containerization Docs

This repository contains concise, practical documentation and Copilot prompts for containerization topics: Docker, Kubernetes, and Helm.

Contents
--------
- Docker guide: [docs/docker.md](docs/docker.md)
- Kubernetes guide: [docs/kubernetes.md](docs/kubernetes.md)
- Helm guide: [docs/helm.md](docs/helm.md)
- Copilot prompt template: [copilot/prompt_containerization.md](copilot/prompt_containerization.md)

Quick start
-----------
1. Read the guides in `docs/` to find examples and best practices.
2. Use the Copilot prompt in `copilot/prompt_containerization.md` to generate project-specific docs.
3. Optionally commit and publish docs to your repo's `gh-pages` or include in your project README.

Contribute
----------
- Add examples or provider-specific notes via pull requests.
- Keep examples minimal and copy-paste friendly.
